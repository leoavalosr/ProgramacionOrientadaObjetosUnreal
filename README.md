# ProgramacionOrientadaObjetosUnreal

Repositorio de prácticas de **Programación Orientada a Objetos en
C++**.\
Este repositorio contiene ejercicios y pequeños programas desarrollados
para practicar conceptos fundamentales de POO.

## Conceptos practicados

-   Clases
-   Objetos
-   Encapsulación
-   Métodos
-   Modularidad
-   Simulación de sistemas simples

## Lista de prácticas

### 1. Autobús (POO)

**Archivo:** `autobus-poo.cpp`\
Simulación simple de un sistema de autobús utilizando clases para
representar el vehículo y su comportamiento.

### 2. Cuenta Bancaria

**Archivo:** `cuenta-bancaria.cpp`\
Implementación de una cuenta bancaria con operaciones básicas como
depósitos y retiros.

### 3. Mini Cacho

**Archivo:** `mini-cacho.cpp`\
Versión simplificada del juego de dados "Cacho".

### 4. Piedra, Papel o Tijera

**Archivo:** `piedra-papel-tijera.cpp`\
Implementación del clásico juego contra la computadora.

### 5. Piedra, Papel o Tijera (POO)

**Archivo:** `piedra-papel-tijera-poo.cpp`\
Versión orientada a objetos del juego Piedra, Papel o Tijera.

### 6. Sistema de Control de Torre

**Archivo:** `sistema-control-torre.cpp`\
Simulación básica de un sistema de control de torre.

------------------------------------------------------------------------

## Compilación y ejecución

Para compilar cualquier archivo:

``` bash
g++ nombre-archivo.cpp -o programa
```

Ejemplo:

``` bash
g++ piedra-papel-tijera.cpp -o juego
./juego
```
