# Programacion orientada a objetos

Clase: plantilla que describe datos y operaciones.
Objeto: instancia de una clase.

Atributos: representan el estado
Metodos: operaciones que modifican o consultan el estado
Encapsulamiento: para ocultar detalles internos 

Constructor: metodo para inicializar objetos.
Invariante de clase: condiciones que siempre se deben cumplir.
